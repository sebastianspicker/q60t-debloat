E/03 From sink to fix

Keep the data.
Remove the interpreter.

The stable fix preserves valid SMB credentials and share names while making it impossible for either helper to parse them as code.

Four claims. Four evidence boundaries.

Privileged sinks

Password-to-mount ran as UID 0. Unmount contains the same share-name shell sink; its disconnect timing remains unresolved.

Live + source Read full report

Persistence bridge

Persistent /opt has enabled boot consumers. The mechanism composes offline; exact TV path replacement and post-reboot attacker execution are unproven.

Static + offline Review boundary

One-shot self-heal

The owner reports replacing existing helpers defensively. No public delivery code, reusable access, independent transcript, or current byte readback is claimed.

Owner-reported See risk status

Vendor fix

Use typed mount and disconnect requests, direct argv, out-of-band credentials, canonical targets, and integrity controls for boot-consumed data.
